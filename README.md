# renaliq
An explainable machine learning framework for kidney disease marker screening among adults with diabetes using NHANES 2017–March 2020 data. Integrates clinical and demographic features with predictive modelling and SHAP-based explainability to investigate kidney health indicators and support data-driven healthcare analytics
Done as part  of HEALTHCARE ANALYTICS COURSE WORK (AY-2026) by Group H , with the team members yadhu , theertha and sreekutty
